# Architecture-to-implementation traceability matrix

Team 1 · Terrapin Events · ENPM 613 · Fall 2026

PA2 supplies the SRS identifiers, PA3 supplies components and decisions D1–D8, and PA4 Tables 10, 14–16 and Figures 10–17 supply detailed responsibilities and interfaces. The source links resolve within the reviewed repository snapshot. [Test runs and release reference](README.md#verified-implementation-baseline)

**Conforms** means the specific element meets the scoped design. **Partial** means a subset or transitional implementation exists. **Deviation** means the implementation uses a materially different design. **Not Implemented** applies to an absent element. The [SAD decision record](SAD.md#implementation-decisions) documents rationale, implications, and the status of course approval.
